## 2. الجزء الأول — مقابلات العيادات (5–8 مقابلات)

### 2.1 خطة التنفيذ

| الخطوة | المسؤول | المدة |
|---|---|---|
| تحديد 8–10 عيادات مرشحة (أسنان/جلدية/تجميل في الرياض) | صاحب المشروع | 2–3 أيام |
| التواصل وتحديد المواعيد | صاحب المشروع | 2–3 أيام |
| تنفيذ المقابلات (2–3 يوميًا) | صاحب المشروع + مساعد | 3–4 أيام |
| توثيق النتائج | المساعد | مستمر |

### 2.2 دليل المقابلة — نموذج لكل عيادة

**المدة:** 30–45 دقيقة | **الموقع:** العيادة أو عن بُعد | **التسجيل:** ملاحظات مكتوبة (استئذان صوتي اختياري)

#### القسم ب: عرض النموذج (15 دقيقة)

> عرض Wireframes أو النموذج التفاعلي إن وُجد. إذا لم يوجد نموذج تفاعلي، تُستخدم الشاشات من `[S1]` مع شرح شفهي للرحلة.

**الرحلة المعروضة:**
1. مريض يبحث عن «تنظيف أسنان» في حي محدد
2. يظهر اقتراح بعيادتكم مع السعر وأقرب موعد
3. يرسل طلب حجز → يصلكم إشعار
4. موظف الاستقبال يفتح الطلب → يؤكد أو يرفض مع سبب
5. المريض يحضر → الاستقبال يسجل الحضور والخدمة الفعلية والمبلغ
6. مدير المنشأة يعتمد المبلغ → تُحتسب عمولة 10%

**أثناء العرض — نسجّل:**

| # | ملاحظة | ما نسجّل |
|---|---|---|
| B1 | ردة فعل أولية | إيجابية / محايدة / سلبية + تعليق حرفي |
| B2 | أسئلة طرحوها | كل سؤال يدل على غموض في التصميم |
| B3 | اعتراضات | كل اعتراض + السبب |
| B4 | مصطلحات استخدموها تختلف عن مصطلحاتنا | المصطلح الفعلي مقابل مصطلحنا |
| B5 | نقاط أعجبتهم | ما يحفّز الانضمام |

#### القسم ج: الأسئلة الحرجة (10 دقائق)

| # | السؤال | ما نسجّل |
|---|---|---|
| C1 | **لو وصلكم إشعار حجز، هل تقدرون تؤكدون خلال 15 دقيقة أثناء الدوام؟** | نعم/لا + الشرط |
| C2 | **مين عندكم يتفرغ لمتابعة الحجوزات طول اليوم؟** | الدور + عدد الموظفين |
| C3 | **لو المريض حجز تنظيف وعند الحضور احتاج تبييض — كيف تتعاملون؟** | آلية تغيير الخدمة |
| C4 | **عمولة 10% من المبلغ المحصل — هل تشوفونها مقبولة؟** | القبول + حد مقبول |
| C5 | **لو المريض ما حضر — هل تتوقعون تُحاسبون على العمولة؟** | فهم سياسة No-Show |
| C6 | **هل عندكم نظام إلكتروني حالي؟ أيش اسمه؟** | التكامل المحتمل |
| C7 | **هل تقبلون تأمين طبي؟ أي شركات؟** | بيانات التأمين |
| C8 | **لو بدأنا تجربة لمدة شهر مجانًا — هل تشاركون؟** | الاستعداد الفعلي |

## 3. الجزء الثاني — اختبارات الاستخدام

### 3.1 المشاركون المطلوبون

| المشارك | العدد | كيف نجدهم |
|---|---|---|
| مرضى محتملون | 5 | معارف / وسائل تواصل / موظفون من خارج الفريق |
| موظفو استقبال | 3 | من العيادات المُقابَلة |
| مديرو عيادات | 2 | من العيادات المُقابَلة |
| مستخدم ثنائي اللغة | 1 | أي مشارك يجيد العربية والإنجليزية |
| مستخدم أصم | 1 | جمعية الصم أو معارف |

### 3.2 سيناريو اختبار — المريض

**المهمة:** «احجز موعد تنظيف أسنان في حي [X] يوم [Y]»

| الخطوة | ما نراقب | نسجّل |
|---|---|---|
| 1. فتح المنصة/النموذج | أين نظر أولًا؟ | نقطة الانتباه الأولى |
| 2. البحث عن الخدمة | هل وجدها بسهولة؟ | عدد المحاولات |
| 3. اختيار العيادة | ماذا قرأ؟ ما أثّر على قراره؟ | معايير الاختيار الفعلية |
| 4. اختيار الموعد | هل فهم التقويم؟ | ثوانٍ للاختيار |
| 5. إرسال الطلب | هل أكمل بدون مساعدة؟ | مساعدة مطلوبة: نعم/لا |
| 6. فهم الرسالة | هل فهم أنه «طلب» لا «تأكيد»؟ | فهم صحيح: نعم/لا |
| — | **الزمن الإجمالي** | ⏱️ ___ دقيقة |

**بعد الانتهاء — نسأل:**
- ما أسهل شيء؟
- ما أصعب شيء؟
- هل تستخدمها لحجز فعلي؟ (1–5)
- وضوح الواجهة؟ (1–5)

### 3.3 سيناريو اختبار — موظف الاستقبال

**المهمة:** «وصلك طلب حجز — أكّده، وعند حضور المريض سجّل الحضور والخدمة والتحصيل»

| الخطوة | ما نراقب | نسجّل |
|---|---|---|
| 1. فتح لوحة الاستقبال | هل وصل بسرعة؟ | ثوانٍ |
| 2. رؤية الطلب الجديد | هل لاحظه فورًا؟ | واضح: نعم/لا |
| 3. تأكيد الحجز | هل عرف الزر؟ | عدد المحاولات |
| 4. تسجيل الحضور | هل فهم الخطوة؟ | واضح: نعم/لا |
| 5. تسجيل الخدمة + المبلغ | هل أكمل بدون خطأ؟ | أخطاء: عدد |
| — | **الزمن الإجمالي** | ⏱️ ___ دقيقة |

### 3.4 سيناريو اختبار — مدير المنشأة

**المهمة:** «عدّل سعر خدمة التنظيف. ثم اعتمد مبلغ تحصيل للمريض [X]. وانظر العمولة المحتسبة.»

| الخطوة | ما نراقب | نسجّل |
|---|---|---|
| 1. تعديل السعر | هل وجد المكان؟ | ثوانٍ |
| 2. اعتماد المبلغ | هل فهم أنه المسؤول الوحيد؟ | فهم الصلاحية: نعم/لا |
| 3. رؤية العمولة | هل المعلومة واضحة؟ | وضوح: نعم/لا |
| 4. رؤية الفاتورة | هل فهم الدورة الشهرية؟ | فهم: نعم/لا |
