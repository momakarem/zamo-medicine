## 0. المبادئ الملزمة

1. ❌ **ممنوع كتابة «تم الاختبار بنجاح» إذا لم يُشغَّل الاختبار فعليًا.**
2. ❌ **ممنوع اختراع نتائج اختبارات.**

4. ✅ عند الفشل: تحديد السبب ← الإصلاح ← إعادة التشغيل ← Regression ← تسجيل النتيجة ← ثم الانتقال.
